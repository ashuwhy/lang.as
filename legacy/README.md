# Legacy AS Lang prototype (2021-2025)

The original bytecode-VM prototype, kept for reference while the new compiler in `../compiler/`
replaces it (see `../docs/DESIGN.md`). It is not part of the Cargo workspace. Its README claims
(SIMD, async/await, constant folding, speedups) were never implemented; see
`../reports/New programming language pain points.md`, "Most of AS Lang's core should be replaced".
